# Chapter 4 Exercises - Artificial Intelligence Programming with Python (Perry Xiao)

This archive contains the Python implementation scripts and modifications for the exercises in Chapter 4 (Deep Learning):

- `exercise_4_1.py`: Single neuron logical OR implementation.
- `exercise_4_2.py`: Multi-Layer Perceptron with 3 inputs.
- `exercise_4_3.py`: Keras MLP classifier with 5 hidden neurons on Breast Cancer dataset.
- `exercise_4_4.py`: LeNet-5 modification with adjusted filter sizes.
- `exercise_4_5.py`: AlexNet modification with customized dense layer units.
- `exercise_4_6.py`: Custom CNN model with extra convolutional and dropout layers.
- `exercise_4_7.py`: CNN with 64 filters and (3,3) kernel.
- `exercise_4_8.py`: Multi-layer CNN for MNIST.
- `exercise_4_9_10.py`: VGG19 model loading and configuration.
- `exercise_4_11.py`: VGG19 webcam image classification setup.
- `exercise_4_12.py`: DenseNet integration.
- `exercise_4_13_14.py`: Modular model selection using if-else statements.
